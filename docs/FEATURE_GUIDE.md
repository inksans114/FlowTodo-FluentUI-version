# FlowTodo RinUI

FlowTodo 的 PySide6 + QML 原生迁移版本。主窗口不再依赖 WebEngine，界面基于
[RinUI](https://github.com/RinLit-233-shiroko/Rin-UI)（Fluent Design 风格 UI 库），
业务逻辑通过 `BackendBridge` / `RinUIBackend` 复用既有 JSON 数据层，保持与旧版本
数据完全兼容。

## 功能

- 今日任务、周任务日程、任务流、项目、专注模式
- 任务流 / 项目编辑器
- 今日任务和日程任务右侧提供“编辑”；编辑和启动准备中可进入“关联任务”流程图，跨集合连接下一项或同时完成的任务。
- 任务流启动准备、项目启动准备、专注进行页
- AI 规划、长期计划预览、账户统计、方块专注历史、每日启动页
- RinUI / Class Widgets 主题、系统明暗模式、窗口材质
- AI 接口配置、开机启动、数据目录设置、灵动岛

### 一小步专注

专注准备页突出目标、时长和开始；关联任务、任务流和高级选项按需展开。任务流保留可复用的连续步骤、休息间隔和所需应用。

- 可选择任务或自由专注，输入这一轮的小目标，使用快捷或自定义时长。
- 可选择进入独立原生 WebEngine 全屏窗口：生长之森 / 专注小屋。场景资源全部本地加载，逐像素深度测试保证旋转遮挡正确；无 WebGL 时自动使用软件深度绘制。树冠平滑生长、轻轻随风摆动，周围有花草；小屋逐渐天亮，电脑显示系统当前时间。左键拖拽旋转，双击复位，方向键 / Home 也可操作视角。关闭“沉浸场景”可使用普通界面。
- 全屏左上角天气入口：默认由 ipapi 查询网络所在城市，再由 Open-Meteo 获取当前天气；雨天、晴天、阴天和雪天影响场景细节。可修改城市或关闭天气，30 分钟内复用查询；联网失败仍可专注。应用不保存 IP 或经纬度，网页不直接联网。天气： [Open-Meteo](https://open-meteo.com/)；定位：[ipapi](https://ipapi.co/)。
- Windows 默认对 WebEngine 使用软件合成，避免共享 D3D 纹理造成动画闪屏，QML 主界面保留原图形后端。场景仍支持三维遮挡与旋转；确认设备支持稳定硬件合成后，可在启动前设置 `FLOWTODO_WEBENGINE_ACCELERATED=1`。
- 雨幕覆盖整个沉浸窗口，雨声可在右上角独立开关，音量在天气设置中调节。音频本地循环播放，离开窗口立即停止；素材为 alxl 的 [Rain on Window Loop](https://opengameart.org/content/rain-on-window-loop)，采用 CC0，详见 `focus-studio/assets/NOTICE.md`。
- 每次完成计时或主动“完成本轮”且已有实际投入时，在 `focus_journey.json` 的 `forest` 中永久保存一棵树；离开、重启和收尾历史截断都不会减少森林。生长之森完成后会留在全屏：视角复位、镜头拉远，同一个 3D 地面向外展开，历史树木一起长大；前 30 棵清晰显示，更多树木在远处重叠淡出，总数仍完整保留。展开后可拖动查看，点击“记录这轮”或 Esc 返回收尾。旧完成记录会迁移为树木，取消与暂停不种树。
- 任务流默认只启动灵动岛，不跳转专注页面、不自动全屏；启动准备中的“开始后进入沉浸场景”可选开启。
- 树冠使用按记录生成的不对称轮廓、不同树形与配色，补充树根、树皮、叶片和苹果；历史树的树下也有花草。森林展开前分帧预热模型，生长过程复用模型，远景降低细节，背面剔除与软件栅格增量插值减少收尾卡顿。
- 可开启番茄钟，设置工作时长、短休息、每 4 轮后的长休息和轮数；自动切换阶段，最后一轮结束进入收尾。休息不计入专注统计。
- 全屏内可暂停 / 继续、暂存念头、完成本轮；`Esc` 返回应用并继续计时，`F11` 切换全屏。“留个接续点”会先暂停再返回接续页。
- 专注中暂存念头（`Ctrl+Shift+Space`），稍后统一处理。
- “需要离开”暂停真实计时；保存进展和下一步后，可退出并在下次启动时恢复剩余秒数。
- 收尾记录实际进展，可保存并休息或继续下一步；只有明确勾选才完成整个任务。
- 进展、接续记录和杂念保存在同一数据目录的 `focus_journey.json`，不修改原有任务格式。

左栏提供“今日任务、AI 助手、专注、进展”和底部“工具、设置”。日程、项目从今日任务右上角进入；小组件、便签在工具页。

新旧版本共享 `%LOCALAPPDATA%\FlowTodo\data`，已有 JSON 数据无需转换。

### 监督模式

- 专注页右上角 → **监督模式**。独立于生长之森／专注小屋，可用原生 QML 全屏或可拖动的置顶小窗；电脑学习默认建议小窗，纸笔学习可选全屏。已有计时会沿用，不重复启动。
- 摄像头检测复用 Google MediaPipe 的 Pose、Hand、Face Landmarker 与 EfficientDet Lite0 预训练模型；显示人物、上半身、手指与眼部关键点。手没入镜会明确提示范围不足，不能用肩膀证明正在学习。眼部方向只是近似辅助线索，低头、眨眼或转头不单独触发提醒。手机与可见手腕靠近且连续出现才提示疑似持手机；“手机学习”允许拿手机。
- 镜头来源可选“手机 · 拍桌面与手部”。默认优先选真实 Wi-Fi／有线网卡，VMware、VPN 等虚拟网卡标为不推荐；手机连同一 Wi-Fi，用系统浏览器扫码，主动开启后置摄像头。电脑开始监督后才接收低频 JPEG，队列只留最新画面；断线不记为分心，暂停停止传送与分析，结束使配对链接失效。画面不经过云端，不存盘。
- 手机浏览器要求安全上下文才能使用摄像头（[MDN](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)），因此使用本机生成的 HTTPS 证书，不使用无法调起摄像头的普通局域网 HTTP。首次访问可能需要安装并信任本地证书，手机页面提供下载和 iPhone 设置说明；请与电脑显示的 SHA-256 指纹核对。此信任只用于该电脑生成的本地相机证书，不关闭浏览器安全检查。
- 手机网页白屏／一直加载时，点“网页打不开？检查连接”切换到普通 HTTP 连通检查二维码。检查页仅提供网络说明和公开 CA 证书，不包含配对密钥、不接收画面；若检查页能打开而摄像头页不能打开，再核对 HTTPS 端口与证书。HTTPS 配对密钥保留在 URL fragment，刷新不丢失；缺少或失效密钥时显示说明，不返回空白页。
- “允许本次局域网连接…”只在用户主动点击并完成 Windows 管理员确认后执行修复脚本。脚本核实当前进程拥有所选 IP 上的两个监听端口，添加限定程序、IP、端口与 LocalSubnet 的放行规则；解除该程序已有的 Public-only 入站阻止规则，不覆盖所有网络的阻止策略、不关闭防火墙、不改变 Wi-Fi 网络类型。规则保留在 Windows 防火墙中，可在高级安全设置按“FlowTodo 手机镜头”找到并移除。
- 监督窗口的“姿态校准”依次采集约 10 个学习、非学习姿态样本；只在本次模式内记录关键点数值，学习个人参考分布。镜头移动后重新校准。样本缺失、两组姿势太相似或当前姿势不接近任一组时不强行判断；只有持续更像用户标注的非学习姿态才提醒，也可以纠正误判。不是重新训练大模型，也不能保证学习真实性。
- Windows 屏幕巡查仅截取当前前台窗口，在本机用 RapidOCR 识别中英文文字，结合应用及用户配置的提醒关键词提示疑似娱乐内容。无法读取、识别不清、普通未知应用及 FlowTodo 自身不会直接记为分心；窗口在 OCR 期间切换时丢弃旧判断。应用白名单沿用已有设置。
- 可选宽松／适中／严格，持续异常才提醒，提醒间隔至少 90 秒。可以回到任务、说明正在查资料、纠正误判或暂停休息；屏幕纠正只临时允许对应窗口 5 分钟，不开放其他窗口。提醒音效独立开关，并遵守全局静音与音量。角色、配音与角色动画未加入。
- 摄像头与屏幕分别需要本次主动确认，授权不随设置保存；不会自动开摄像头、麦克风，不录像、不保存截图或 OCR 原文，不上传画面、不调用付费 API。暂停、休息、等待 AI 下一步和结束时停止采集，旧结果不再触发提醒。停止监督保留原计时；“结束本轮”结束计时。AI 引导到点可返回 AI 场景继续决定下一步。
- 摄像头不可用、权限拒绝、设备占用、模型初始化失败或画面过暗时显示具体状态，不将技术故障判为分心。这些检测只能提供可见迹象，不能确认是否认真学习、敲键盘或正确写代码；效果需要实际光照、机位和设备测试。
- 源码首次运行执行 `python tools/prepare_supervision_models.py`，只从 Google 官方下载四个模型，随后离线使用；已有模型会校验后保留，只补齐新增模型。正式包内附模型。模型来源与说明见 `supervision-models/NOTICE.md`，`manifest.json` 记录版本 URL 与 SHA-256。
- 验证：`python -m unittest discover -s tests`；`python tools/supervision_preview.py` 检查原生页面与监督生命周期，不开启真实采集；`python tools/supervision_model_check.py` 使用 Google 公开姿态示例图片及自行绘制的文字进行真实模型推理，会联网读取示例图片，不读取用户画面。
- `build_nuitka.bat` 已加入本地模型、OCR 模型与 MediaPipe DLL 的打包配置；`--check` 只预检。正式 Nuitka／PyInstaller 打包由用户运行并查看进度，代理不等待或轮询编译。

### 轻量开始与任务归档

- 专注页默认只显示目标和开始按钮，目标可留空。首次使用从 5 分钟开始，记住上次的时长、番茄节奏和沉浸选择；默认使用普通界面，更多设置按需展开。
- 设置 → 应用与数据 → 普通任务自动归档：关闭 / 三天 / 一周 / 两周，默认关闭。只归档普通未完成任务，保护每日重复、番茄钟、项目关联、长期 / AI 和特殊任务，以及当前专注绑定的任务。未来排期不会提前归档。
- 归档保存在原任务数据文件中，可从同一设置页打开归档列表并恢复到今天；不计作完成，不增加成就。新任务从创建、调整排期或恢复时间计时，无时间记录的旧任务享有从首次识别起的完整宽限期。
- 单次专注和番茄周期结束后，灵动岛保留“休息 / 再一轮 / 收起”。休息不计入专注统计和种树；再一轮保留任务与工作时长。番茄周期可自定义每几轮安排长休息，结束后选择休息会沿用该节奏。
- 任务流仍保留原来的顺序与自动切换逻辑，沉浸场景由启动准备中的选项控制。

### AI 助手与随口记录

- 今日任务 → “随口记下”是独立快速录入页，默认只使用系统听写／文字，不接入 AI。换行、分号或句号分隔可批量记下，预览后可改标题、分类或取消某项；保存后清空输入，继续下一批。每批使用独立标识和新任务 ID，重复点击同一批不重复添加，新一批同名事项也不会覆盖原任务。未提交草稿独立保存在本机 `quick_capture.json`。
- 可选“AI 拆分与分类”仅发送当前这段原话与短提示词，一次请求、1600 token 输出上限，不带旧对话、任务列表或偏好，不产生专注步骤与问卷。返回后确认才新增；失败、截断或拦截均保留原话，不自动追加付费请求，可直接记录或缩短后重试。
- AI 助手仍提供动态引导与已保存方案；“新的想法”可另起一份，旧方案留在方案库，不混入快速录入草稿。快速录入无论语音服务设置如何，均优先使用系统听写；云端语音继续在 AI 助手中按用户设置提供。

- 左侧导航直接打开 AI 助手：语音或文字说明事项和状态 → 只询问缺少的关键问题（最多 3 项）→ 根据回答准备当前 1–3 段。可以偏好小块起步，也可以整张卷子、整个模块推进；没有固定的五分钟模板。信息明确时直接准备，不强制问卷。
- 点击“准备好了，带我开始”进入全屏，只显示当前动作。计时到点等待用户确认，可选择还没做完、休息或调整节奏；下一批依据实际反馈准备。已准备的步骤和倒计时不持续调用 API，补充回答、下一批和重新规划需要请求。明确完成后有礼花与可关闭的原创庆祝音效，静音设置同样有效；休息不计入专注时长，不自动宣布作业完成。
- AI 沉浸引导中可点击“告诉 AI 当前进度”，用一句话或科目、材料、题型、题号字段报告实际进展。AI 信息不足时在场景内给最多 3 个问题和选项，也可自由回答或选择按已知信息安排；选项由模型根据已有材料生成，不固定三张卷子。最新报告和回答会随下一段请求发送，保存在本地接续记录，切换科目不会自动完成待办。
- AI 助手和详细规划右上角的“已保存方案”可搜索、重新打开或另存独立副本。新结果自动保存在本机 `ai_state.json`，新方案不覆盖旧方案，清空对话不删除方案。原话、未提交的问题回答、任务标题编辑、勾选状态会随页面切换恢复；普通和长期规划也保留。旧 `ai_plans` 结果文件会在首次升级时加入列表，损坏的文件保留原文件并跳过。
- 保存的 AI 引导附带步骤、剩余时间、进度报告和待答问题，暂停后可从方案列表继续；多个已停下的方案独立保存。打开、复制和恢复计时不请求模型，也不重复计算已记录的专注时间。已有计时正在运行时先留接续点再切换。方案仍使用原有本地数据目录，不上传历史方案库、不设自动删除上限；清除所有用户数据会同时清除这些方案。
- 可在进度输入框或“AI 服务与偏好”中开启每 10 / 20 / 30 分钟的进度询问，默认关闭。间隔按实际专注时长计算，休息、暂停、填写、等待 AI 时不弹出；询问可跳过，关闭后继续原来的计时。提醒本身不调用 API，提交进度或回答才请求 AI。
- AI 引导中的任务草稿默认折叠，可单独编辑、勾选、合并添加，不自动覆盖既有任务。有长期计划时仍能使用独立快速录入。AI 引导原话保存在本地 AI 状态中，请求失败后可以继续修改；未明确排期的 AI 草稿不会被强制安排到某一天。
- 提示词区分背景、否定、改口与真实行动意图，使用紧凑上下文和有限历史。短期输出默认上限 1800、长期 3600 token，可在服务高级选项调整；截断、上下文超限或 JSON 不完整时最多紧凑重试一次，不导入残缺结果。服务内容拦截会明确报错，不重试绕过。
- 超过 6000 字的原话按顺序分段提炼，保留原文，界面提前显示大约请求次数；超过 20000 字要求分批补充。分段与重试可能增加费用，实际语义理解和信息保留质量取决于模型，模拟测试不能保证真实模型的表现。
- 语音默认使用 Windows 系统听写：点击语音按钮，自动聚焦输入框并唤起 `Win + H`。无需 API 密钥，不调用 FlowTodo 的 AI/语音接口；只有请求 AI 整理时才使用 AI API。Windows 听写需联网、可用的麦克风和系统相应权限（[微软说明](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)）；由系统管理听写面板和停止监听。如果没有弹出，可点击输入框自行按 `Win + H`。应用不在前台或输入框失焦时不会发送快捷键。
