# 详细规划接入现有软件数据

详细规划页面通过 `RinUIBackend.applyAiPlan` 合并导入原有待办、任务流与项目数据库，并发出原来的数据刷新信号。带日期任务由原生日程读取；明确且唯一匹配的任务流步骤关联待办 ID，因此可沿用原有专注与完成状态链路。

长期方案的已生成周期任务按日期落入日程。同名任务按日期与时间区分，重复导入不会删除或替换现有 AI 内容；已保存方案记录首次导入日期，后续导入保留相同日期锚点。不会自动开始专注或替换正在运行的长期计划。

云端下载的方案使用本机方案 ID 重建 `libraryId`，并进入“已保存方案”原有打开流程。打开后可继续导入到任务生态，不另生成一份孤立方案。详细规划导入失败会明确提示错误，成功会报告新增数量。

验证：隔离临时数据中实际点击详细规划导入按钮，检查待办、任务流关联、项目、三日同名任务日程、重复导入、错误提示和云端方案身份；未修改用户记录或调用付费 AI。
