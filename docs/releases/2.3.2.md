# FlowTodo 2.3.2

- 补全英文、繁体中文界面翻译，覆盖 AI 助手、新设置页面和弹窗；语言选择移至外观设置。
- AI 助手根据当前界面语言生成计划、任务说明和引导内容，保留用户原文与结构化数据。
- 全新关于与软件更新页面，展示版本、发布说明、下载进度和自动更新开关。
- 更新下载完成后等待用户确认安装；确认更新助手成功启动后再退出，减少更新过程中无声退出的问题。
- 增加运行日志和软件渲染兼容启动脚本，方便排查启动与显示异常。

## Windows 使用方法

下载并完整解压 `FlowTodo-Windows-x64-2.3.2.zip`，运行文件夹中的 `FlowTodo.exe`。请勿只复制 exe。

如遇显示或启动异常，可尝试同目录的 `start_compatibility.bat`。运行日志保存在 `%LOCALAPPDATA%\FlowTodo\logs`。
