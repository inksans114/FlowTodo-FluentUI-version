# FlowTodo 2.3.1 · 让想法，有下一步

把想法、计划和专注接到一起。这一版加入了完整的 AI 方案工作流与云端记录管理，也整理了日常桌面体验。

- AI 动态引导、详细规划与方案库；计划可导入待办、任务流、项目与日程。
- 快速录入与系统听写，AI 拆分按需使用。
- 生长之森、专注小屋、番茄节奏、进展回顾与接续点。
- 桌面账户登录、官方 AI 通道和自定义接口；软件内同步、导入与管理云端记录。
- 更简洁的待办组件，设置子页补上返回入口。
- 修复账户文字与图标、徽章、主题预览的对齐，以及语音条展开挤压帮助按钮的问题。
- 轻量展开、按压与浮层动画，遵循减少动态效果设置。
- 修复英文 Windows 下中文目录的自启动快捷方式保存。
- 重新设计 GitHub 介绍页，加入 7 张真实运行截图与上手说明。

## 下载与升级

下载 `FlowTodo-Windows-x64-2.3.1.zip`，完整解压后运行 `FlowTodo.exe`。保留同目录下的资源文件。

用户数据默认位于 `%LOCALAPPDATA%\FlowTodo\data`，升级前建议备份。`SHA256SUMS.txt` 可用于核对文件完整性。源码压缩包不是打包好的 Windows 程序。

## 功能说明

本地待办与基础专注无需登录；云端与官方 AI 需要联网和对应账户权限。监督模式需主动开启，检测只作辅助提示。macOS 为独立测试构建。

专注历史自动上传网站、增量自动更新不列为本次已验证功能。图片使用演示记录，AI 与检测效果取决于模型、设备和环境。
