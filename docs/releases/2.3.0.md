# FlowTodo 2.3.0

围绕“记下想法、导入计划、开始专注”完善桌面工作流，整理账户、云端记录与界面细节。

- AI 动态引导、详细规划与已保存方案；详细规划导入待办、任务流、项目与日程，重复导入减少重复记录。
- 独立快速录入，支持系统听写和可选 AI 拆分。
- 生长之森、专注小屋、番茄节奏、进展回顾与接续点。
- 桌面登录、账户类型展示、官方 AI 通道与自定义接口；云端记录支持同步、导入、删除和恢复。
- 简化桌面待办组件，设置子页补充返回入口。
- 修正账户徽章、文字图标、灵动岛主题预览对齐，以及语音条展开挤压帮助按钮的问题。
- 语音条与帮助浮层加入轻量动画，支持系统减少动态效果设置。
- 可选本地监督与手机镜头，需主动开启，识别结果只作辅助提醒。
- 仓库介绍页补充真实运行截图、上手步骤和功能边界。

Windows 请完整解压发布 ZIP，再运行 `FlowTodo.exe`。用户数据默认位于 `%LOCALAPPDATA%\FlowTodo\data`，升级前建议备份。云端功能需要联网及账户权限；macOS 为单独的测试构建。

本次未将专注历史自动上传网站、增量自动更新列为已验证功能。图片使用演示记录，AI 和监督检测表现取决于模型、设备与环境。
